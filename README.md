## 🚀 How to Publish & Open on GitHub Pages

If you created a GitHub repository and the link is not opening the website, follow these quick steps:

### 1. Ensure `index.html` is at the ROOT of your repository
- In your GitHub repo, you should see `index.html`, `css/`, `js/`, and `assets/` directly on the front page.
- ⚠️ **Common Mistake**: If you uploaded a folder called `Dosa shop` and all files are inside `Dosa shop/index.html`, GitHub Pages won't find it. Move the contents directly to the root of the repository.

### 2. Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click **Settings** (tab at the top right).
3. In the left sidebar, click **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and set the folder to `/ (root)`.
   - Click **Save**.
5. Wait **1 to 2 minutes** for GitHub to deploy your site.
6. Refresh the page: GitHub will display your live website link at the top:
   ```
   https://<your-username>.github.io/<repository-name>/
   ```

### 3. Ensure Repository is Public
- On free GitHub accounts, GitHub Pages is only available for **Public** repositories.
- If your repo is Private, go to **Settings** → **General** → scroll down to **Danger Zone** → click **Change repository visibility** → set to **Public**.
